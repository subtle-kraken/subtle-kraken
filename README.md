### subtle-kraken

Security, data and machine learning for defence and critical systems.

I work where cybersecurity meets data science: protecting systems that have to keep running, and using data to see threats earlier. My background is in information security (CISSP) and applied data science, in regulated environments where reliability and traceability matter.

**Interests**

- 🛡️ Cyber defence and the security of critical infrastructure
- 📡 Multi-sensor detection and data fusion, such as counter-UAS
- 📊 Anomaly detection, time-series analysis and model monitoring
- 🔌 Embedded and IoT systems: ESP32, Arduino and edge devices
- 🤖 Applied ML and LLM agents for analysts

**Toolbox**

Python · pandas · scikit-learn · XGBoost · SQL · Docker · Linux · C++ (Arduino/ESP32) · Kotlin

**Public projects**

| Project | What it is |
|---|---|
| [HumidityHouse](https://github.com/subtle-kraken/HumidityHouse) | Sensor network that logs indoor and outdoor humidity and temperature, with time-series analysis of where the moisture comes from |
| [PlantAutonomousSystem](https://github.com/subtle-kraken/PlantAutonomousSystem) | ESP32 controller that waters a plant on its own, with a local web interface, thresholds and alarms |
| [LottoPrediction](https://github.com/subtle-kraken/LottoPrediction) | Random Forest and XGBoost models trained on past lottery draws, as a test of how far models can go on random data |

**Currently exploring:** multi-sensor drone detection (radar, RF, optical and acoustic fusion) and drift monitoring for ML models in production.
